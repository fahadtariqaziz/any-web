# Explaining test results

Use when the patient shares a number from a test, a meter or a lab report and asks what it means.

Steps:
1. Repeat the value with its unit and ask for the unit if it is missing (mmol/L vs mg/dL changes everything).
2. Explain in plain words what the test measures and why doctors check it.
3. Say how the value compares with the reference range printed on their report (ranges differ between labs);
   if you cite a commonly used range, name the source (use search_knowledge or the research you have).
4. Explain what usually influences the value (meals, time of day, stress, medicines) and that one value is a
   snapshot: the trend matters.
5. End with what to ask their doctor ("Is this value on target for me? Should my plan change?").

Never: diagnose from a value, say a value means they can change or stop medication, or reassure that a clearly
dangerous value is fine. Very high or very low readings with symptoms (confusion, chest pain, fainting): urgent care.
